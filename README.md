# PV Repowering Tools and Case Studies

This repository collects data, models, and analysis tools related to **photovoltaic (PV) repowering**, including economic screening, case studies, and supporting materials developed through research and industry engagement.

The initial contents support the study:

> *A Practical Framework for Repowering Decisions in Aging Photovoltaic Systems* (submitted)

and are intended to provide transparent, reproducible inputs for evaluating repair, reinstallation, repowering, redevelopment, and second-life reuse decisions across PV system types.

## Scope

This repository is designed to grow over time and may include:
- Techno-economic models for PV repowering evaluation  
- System Advisor Model (SAM) input files and parametric studies  
- Cost calculators and screening tools for repowering decisions  
- Case studies (residential, commercial, utility-scale, and second-life)  
- Supplementary data, assumptions, and sensitivity analyses  
- Related repowering research outputs and documentation  

## Current Contents

- Modeling files supporting residential, commercial, and second-life repowering analyses  
- Cost and lifetime assumptions derived from literature and stakeholder interviews  
- Example scenarios illustrating tradeoffs between payback time and net present value  

## Intended Use

These materials are intended for:
- PV system owners and operators  
- EPCs and consultants  
- Researchers and analysts  
- Policymakers and program managers  

The tools are designed for **screening and comparative analysis**, not as a substitute for detailed site-specific engineering or permitting review.

## Disclaimer

All results are based on assumed costs, lifetimes, and operating conditions. Actual repowering outcomes will vary depending on site conditions, regulatory context, equipment compatibility, and market factors. Users are responsible for validating assumptions for their specific applications.

## Citation

If you use materials from this repository, please cite the associated publication and any referenced software tools as indicated in the documentation.
